01 / The input

How can an image be numbers?

What does a computer actually receive when it sees a photo?

An image is a grid of pixels. A grayscale pixel has one intensity; an RGB pixel has red, green and blue values.

RGB values describe the same location. Change them to change that pixel’s colour.

Select a pixel to inspect it.

Pixel · row 4, column 4

8-bit values: 0–255.
Training often rescales them to 0–1.

Shape = height × width × channels.
A channel is one grid of values.

Image representation provides a numerical grid: height × width × channels.

02 / The bridge

What does an MLP miss?

Would moving an object change what it is?

Flattening preserves the values, but a dense layer does not build in spatial neighborhoods or reuse one detector at every location.

2.1Every pixel gets a separate weight

First dense layer: 128 neurons

Every input connects to every dense neuron.

Flattened inputs
Weights + 128 biases

Just one layer: more weights mean more memory and more opportunity to overfit limited data.

Local connectivity

A dense layer does not privilege neighbouring pixels over distant ones. Convolution begins with a small patch, where local patterns form.

Weight sharing

Slide the same detector everywhere. Its weights stay the same.

2.2The same edge, in a different place

Dense weights belong to fixed pixel positions. Moving an edge changes which weights it meets. Convolution reuses one local detector everywhere.

One illustrative detector, with bias 0

Input · 5 × 7
One vertical line of 1s

Same pattern, new position

Dense neuron · fixed weights
Three weights = 1; others = 0

Shared 3 × 3 filter

This illustrates one neuron, not a trained classifier. A convolution’s response moves with the pattern (equivariance); the final prediction is not automatically invariant.

Three limitations: dense layers use many parameters, do not privilege nearby pixels, and do not automatically reuse a detector across locations. CNNs build in locality and sharing.

03 / A sliding detector

First, a filter designed by hand.

How can nine numbers detect an edge?

Sobel filters detect intensity changes. One responds to vertical edges; the other responds to horizontal edges.

Sobel x subtracts the left from the right. Uniform patches cancel to zero; a brighter right side gives a positive response. Reverse the contrast, and the sign reverses.

Input image

Sobel x · vertical edges

Sobel y · horizontal edges

Edge previews show response magnitude, scaled for display. The calculation below retains the sign.

3.1One patch becomes one number

  1. Multiply matching positions. Each patch value meets one filter weight. This is elementwise multiplication, not matrix multiplication.

  2. Add the products and one bias. Nine products from a 3 × 3 patch become one output value.

  3. Move and repeat. Write the result at the matching output position. Reuse the same weights and bias.

Input · 6 × 6 · values 0 or 1

Filter · 3 × 3 · fixed Sobel weights

Patch × filter · multiply each pair

Feature map · 4 × 4

PositiveNegative

Amber links one input, its weight and their product. Finish all nine products, then add the bias.

The output of one filter is a feature map: a grid of responses. Each value describes one input neighbourhood. Strong positive responses mark strong matches; the map shows where they occur. These are activations, not image colours.

Classical image processing

People designed filters such as Sobel. The filter values were fixed.

Convolutional neural networks

Weights and biases are trainable. Backpropagation combines gradients from every use of a shared weight. The task determines useful detectors; they need not resemble Sobel.

Convolution provides feature maps with shared detectors. One grayscale 3 × 3 filter needs only 9 weights + 1 bias = 10 parameters, regardless of the number of positions.

05 / Controlling shape

Padding, stride and output size.

How many places can the filter fit?

Padding adds a border. Stride is the distance the window moves. Neither introduces trainable weights.

5 × 5 input · 3 × 3 filter
Striped cells are zero padding.

Valid window positions

Padding 1 and stride 1 preserve size for a 3 × 3 filter. Larger stride usually gives a smaller output.

Subtract the kernel to find available travel. Divide by stride to count moves. Round down; add 1 for the starting position.

Output size = floor((input + 2 × padding − kernel) / stride) + 1Apply separately to height and width. Padding is per side. Floor means round down.
Standard windows: no dilation; equal padding on opposite sides.

06 / Local summaries

Pooling reduces spatial size.

Do we need every exact feature location?

Pooling applies a fixed summary rule independently to each channel. Standard max and average pooling have no trainable weights or biases.

Max poolingKeeps the strongest response. Preserves prominent features; discards weaker ones.
Average poolingKeeps local mean strength. Smooths responses; isolated peaks become weaker.
Global average poolingAverages each entire feature map into one value. Removes spatial layout; can replace flattening.

Output · 2 × 2 · same channel

2 × 2 window · stride 2 · padding 0

Pooling provides compact summaries while preserving channels. The same output-size formula applies; use the pooling window as the kernel.

Pooling trades spatial detail for a compact representation. It does not guarantee translation invariance.

07 / From features to a decision

Fully connected: combine the evidence.

How do detected features become a class?

Flatten rearranges feature values into a vector; it learns nothing. In a fully connected (dense) layer, every neuron uses every input, with its own weights and bias.

Two 2 × 2 feature maps → 8 values

Same values. Different arrangement.

Each neuron computes weighted inputs + bias. Hidden dense layers usually add an activation; a final classifier produces logits. Softmax converts these scores into class probabilities.

Parameters = (inputs + 1) × neurons

Fully connected layers combine extracted evidence into predictions; their weights are learned.

08 / The complete network

LeNet: a landmark in recognising digits.

Can these simple operations recognise handwriting?

LeNet-5, described by LeCun and colleagues in 1998, learned handwritten digit recognition. Related convolutional systems read bank cheques—an early practical success for learned visual features. Original paper.

We trace a teaching adaptation: ReLU, max pooling, full channel connectivity and a dense classifier differ from historical LeNet-5. Conv: kernel 5, stride 1, padding 0. Pool: window 2, stride 2. Biases included.

Activations ≠ parameters. Conv1 produces 4,704 values per image using just 156 shared parameters. Larger input images increase computation, not the weights of a fixed convolution.
Why do the dense layers contain most of the weights?

Dense1 connects all 400 features to all 120 neurons: 48,000 weights plus 120 biases. It alone contains about 78% of this network’s parameters.

LeNet combines the operations into a trainable image classifier.
