Why the RNN forgets

Review A

Problem

Each word enters the network as 4 numbers.

Key ideaBy the last word, h_t mostly reflects “Sunday evening”, not “brilliant”.

2

A memory lane: the notebook

Review A

The RNN rewrites its only memory at every word. Give the reader a notebook that is never rewritten.

ProblemThe RNN has no safe place to keep “brilliant”.

FixAdd a notebook C_t. Each word adds its proposal \Cn: + for good, − for bad. The proposal uses tanh, so it is between −1 and 1.

Key ideaNothing in the notebook is rewritten, only added. “brilliant” survives the long gap.

3

The notebook cannot forget

Review B

The notebook kept “brilliant”. Now read Review B, where the opinion flips at “but”.

Problem“long” and “slow” make the notebook negative. At “but” nothing can erase it.

ProblemSmall words keep adding too.

Key ideaThe notebook needs 3 controls: an eraser (what to erase), a pen (how firmly to write) and a voice (what to say).

4

The gate

Each control is a gate. A gate is a neuron you already know.

ProblemA control must be able to be partly on, not only on or off.

FixA gate is the same Σ neuron with \sigma (sigmoid) in place of tanh. It gives a number from 0 to 1 and multiplies a signal by it.

Drag the point, or focus it and press the arrow keys.

Key ideaA gate near 0 blocks the signal. A gate near 1 lets it all pass.

Why the LSTM learns long gaps

Review A

In training, the error at the verdict travels backward to every word to adjust the weights. If it fades before “brilliant”, the network never learns that “brilliant” mattered.

Problem

Key ideaIn the notebook the signal is multiplied by \Fg \approx 1, so it stays strong.

8

The GRU

Review B

The GRU uses the same idea with fewer parts. The notebook and what you say become one memory h_t.

Update gate: keep or write

One gate \Zg splits the work: keep 1-\Zg of the old memory, write \Zg of the proposal \Hn, just like \Cn in the LSTM.

Reset gate: a fresh proposal at “but”

Summary: from LSTM to GRU

Key ideaOne slider \Zg keeps 1-\Zg of the old memory and writes \Zg of the new.

Bidirectional RNN

Some words are understood only from the words after them.

ProblemA forward reader reaches “Teddy” after reading only “He said”. Both sentences look the same.

FixAdd a backward reader that reads right to left. Join both at every word.

Forward reader at “Teddy”
has read “He said Teddy”. It cannot tell toy from person.
Backward reader at “Teddy”
has read “bears are on sale” (a toy) or “Roosevelt was a president” (a person).
bidirectionalh_t = [\,\text{forward } h_t\ ;\ \text{backward } h_t\,]
